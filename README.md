# 驅魔實驗室

給驅魔勇士和驅魔師使用的定課紀錄網站：每日打卡、心路歷程、留言板。

- `index.html`：網站本體，由 GitHub Pages 提供。
- `apps-script.gs`：Google Apps Script 後端，安裝步驟寫在檔案開頭。

紀錄存在部署者自己的 Google 試算表。打卡和紀錄不需要登入；留言板、心路歷程和修改規則要用姓名和密碼登入。心路歷程只有驅魔勇士本人能寫和看。留言在公布前只有寫的人自己看得到；驅魔勇士也可以留言給其他驅魔勇士。規則只有邱子芸能改。每月 15 號和 30 號（沒有 30 號的月份在月底）會把之前的留言公布到「公佈欄」，登入的人都看得到，並顯示是誰寫的。每次公布後的三天內（公布當天算第一天），每次打開公佈欄都會先跳出一段要先念一遍的話，按「確認」後才看得到留言。

驅魔勇士名單由邱子芸在「規則」分頁新增，新加入的人從加入當天開始算。

每位驅魔勇士登入後，可以在「規則」分頁選自己的定課菜單，彼此互不影響。

每位驅魔勇士還可以有一項「驅魔師C圈訂制」的專屬定課，由邱子芸在「規則」分頁的專屬定課區為每個人分別填寫，會以特別的樣式出現在那個人打卡頁的最上面。

打卡期限是隔天中午 12 點，過了就鎖定。要改已鎖定的日期，到試算表的「打卡」分頁修改該日該驅魔勇士那一列。

## 驅魔實驗室 2

`lab2/` 是另一間實驗室，驅魔勇士只有姵蓉，沒有驅魔師、留言板和公佈欄，網址是 `/exorcism-lab/lab2/`。它有自己的 Apps Script 後端（`lab2/apps-script.gs`）和自己的試算表。邱子芸是管理者，不在打卡名單裡，登入後可以修改規則、實驗期間、定課菜單和密碼。
