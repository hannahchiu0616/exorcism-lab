# 驅魔實驗室

給三位實驗者（邱子芸、江宇熙、邱家瑋）和觀察者使用的定課紀錄網站：每日打卡、心路歷程、留言板。

- `index.html`：網站本體，由 GitHub Pages 提供。
- `apps-script.gs`：Google Apps Script 後端，安裝步驟寫在檔案開頭。

紀錄存在部署者自己的 Google 試算表。打卡和紀錄不需要登入；留言板、心路歷程和修改規則要用姓名和密碼登入。心路歷程只有實驗者本人能寫和看。留言只有寫的那位觀察者看得到，實驗者不能看，規則只有邱子芸能改。

每位實驗者登入後，可以在「規則」分頁選自己的定課菜單，彼此互不影響。

打卡期限是隔天中午 12 點，過了就鎖定。要改已鎖定的日期，到試算表的「打卡」分頁修改該日該實驗者那一列。
